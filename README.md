# CosmoCalc

One vibration, six doors. Angle · Color · Frequency · Length · Grade · Unbound.

A harmonic correspondence calculator mapping angle = hertz = length = overtone = color, built on honest math with no fudge factors. Root D = 288 Hz = Green at North (90°); A = 432 Hz = Red at South West.

**Live at [www.baguafx.com](https://www.baguafx.com)** · Delphic Arts & Dowsing Design

## Features
- Five conversion doors: Angle, Color (nm), Frequency (Hz), Length, Grade
- Unbound Angle door: raw degrees + grades glyphs, not bound to 432
- Overtone readout in scientific notation
- Universal Pendulum readout
- Length converter (m, cm, ft, in)
- Journal
